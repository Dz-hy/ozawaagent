# 05 — 高危执行确认流

**What to build:** 首次执行带风险标签（写、删除、Shell、网络、凭据、常驻）的能力时，GUI 弹出确认对话框，展示来源与风险标签；用户批准后执行才继续，拒绝则终止；确认/拒绝结果回传 GA runtime 并计入审计。
